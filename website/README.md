# EyeDataHub Docs (Docusaurus)

Static documentation site for EyeDataHub. Every resource in the catalog has
an auto-generated Markdown page with:

- Copy-paste `eyehub download` command and Python snippet
- Loader status and an example when a standard loader exists
- BibTeX and plain-text citation in tabs
- License screening label with a source review reminder
- Related-dataset links within the same modality
- Upstream dataset links and source citations

## Regenerate dataset pages

```bash
# From the repo root
python -m hub.docs.generate_dataset_pages --out website/docs
```

This writes:

- `website/docs/datasets/<name>.md` - one per catalog resource (386 today)
- `website/docs/datasets/<modality>-index.md` - one per modality
- `website/docs/datasets/index.md` - top-level datasets landing
- `website/sidebars.js` - auto-generated sidebar manifest
- `website/docs/url-audit.md` - latest URL-audit report when generated by CI

## Local Development

```bash
cd website
npm install
npm run start      # http://localhost:3000
npm run build      # static site -> build/
npm run serve      # serve the built site
```

## Deployment

Any static host works. The `docusaurus.config.js` `baseUrl` is set to
`/EyeDataHub/`. GitHub Pages publishes the site at
`https://khosravipooya.com/EyeDataHub/`.
